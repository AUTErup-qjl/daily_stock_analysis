# 飞书测试脚本安全修复

`scripts/quick_test_feishu.py` 不再带有默认机器人地址。使用前通过环境或本地秘密管理器配置已有的 `FEISHU_WEBHOOK_URL`。不要将真实地址放入源码、截图、命令历史或日志。

两个测试脚本仍会在明确运行时向配置的机器人发送测试消息。本次只使用替身模块离线验证，没有调用真实机器人。

修复隐藏完整 URL、签名 secret、原始响应和异常详情，保留 HTTP 状态与服务返回代码用于诊断。没有更改消息用途或通知主程序。

代码清理不会撤销旧地址，也不会移除 Git 历史中的已泄露内容。应先在飞书确认机器人并撤销/更换地址，再更新合法消费者。历史重写需另行确认影响范围。

此说明对应中文诊断脚本；没有既有英文专题对应页，因此未新增平行英文文档。
